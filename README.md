# Hydraulic Leakage Prediction Demo

An interactive, static webpage explaining a scikit-learn Random Forest model built with the public UCI Condition Monitoring of Hydraulic Systems (ZeMA) dataset.

The model summarizes pressure, motor-power, and temperature readings from stable 60-second cycles and classifies the pump leakage condition as none, weak, or severe. It was evaluated with five grouped validation folds.

The page is a GitHub Pages-ready static site: publish `index.html` from the repository's main branch and root folder.
